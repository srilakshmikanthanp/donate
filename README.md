# Donate

Donation page for [Sri Lakshmi Kanthan P](https://srilakshmikanthanp.com), built with Vite, React and Tailwind CSS.

## Scripts

- `npm start` – dev server
- `npm run build` – type-check and build to `dist`
- `npm run lint` / `npm run format`
- `npm run deploy` – publish `dist` to GitHub Pages

To add or remove a donation platform, edit `src/constants/index.ts`.
